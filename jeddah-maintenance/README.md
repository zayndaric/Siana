# صيانة جدة - المركز المتخصص في صيانة الغسالات الأوتوماتيكية والثلاجات

موقع رسمي وتفاعلي بالكامل لخدمات **صيانة جدة (Siana Jeddah VIP)**، مصمم وفق نظام التصميم التقني الحديث بالنمط الفاتح (Light Theme) بألوان الأبيض والأزرق الفاتح والكحلي الملكي `#101B5D` ومتوافق تماماً مع جميع متصفحات سطح المكتب والأجهزة الذكية.

## 🌟 المميزات الفنية
- **تصميم تقني فاخر بالنمط الفاتح (Light Theme):** متوافق مع لوحة ألوان الشعار (الكحلي الملكي `#101B5D` مع خلفية بيضاء نقية وتدرجات الأزرق الفاتح `#F0F7FF` و `#0284C7`).
- **هيدر بانورامي متحرك مخصص (Panoramic Animated Header):** مع تأثيرات حركية فاخرة وزوايا هندسية متطورة تغطي كامل رأس الصفحة.
- **تأثيرات حركية متناسقة:** بطاقات رفع تفاعلية عند التمرير (Hover Lift)، تأثيرات تموج ونبض للأزرار، وحركات دخول سلسة.
- **تصفح متعدد الصفحات:**
  - `index.html` - الصفحة الرئيسية مع لافتة الهيدر التفاعلية واستعراض الخدمات ونموذج الحجز السريع.
  - `refrigerators.html` - صفحة صيانة الثلاجات والفريزرات، تشخيص الأعطال، ودليل الحفاظ على الأطعمة.
  - `washing-machines.html` - صفحة صيانة الغسالات الأوتوماتيكية، أعطال الطرد والعصر، وفحص الكروت الإلكترونية.
  - `contact.html` - صفحة الاتصال المباشر ومساعد التشخيص الذكي التفاعلي ومحرك الحجز المنزلي.
- **تكامل مباشر مع واتساب:** توليد رسائل مهيأة تلقائياً برقم مرجعي للمتابعة بنقرة واحدة.
- **قائمة هاتفية متجاوبة:** درج ملاحة متنقل للأجهزة الذكية (Mobile Navigation Drawer).
- **محتوى معتمد ومرخص:** تمت صياغة المحتوى باحترافية تسويقية وتقنية عالية تركز على الجودة والكفاءة.
- **جاهز للنشر الفوري على Vercel:** يتضمن ملف `vercel.json` للتوجيه النظيف والتخزين المؤقت للأصول.

## 🚀 النشر على Vercel
1. اربط مستودع GitHub بحسابك على Vercel.
2. اضغط على **Deploy** دون الحاجة لأي إعدادات خاصة (موقع ثابت فائق السرعة).
